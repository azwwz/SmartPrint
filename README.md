# SmartPrint

Windows 上的**手动双面打印管理工具**，专门给不支持自动双面的打印机用（比如 HP LaserJet 1020）。

它不负责「把 PDF 发给打印机」——这件事任何阅读器都能做。它负责另一半：

- 一次只发**一页**，你到打印机那儿核对过、确认完整出纸，才发下一页；
- 一批纸的正面全打完，才提示你翻面，并告诉你往哪个方向翻；
- 中途卡纸、缺纸、纸印糊了，把**整张纸**（正反两面）作废，本轮结束后统一补打，不必从第一页重来；
- 崩溃、断电、误关窗口之后，进度还在数据库里，不会重复打印已经确认过的纸。

一句话：**它管的是「哪些纸已经打好、还剩哪些纸要打」。**

> 本文是快速上手。界面各列的完整含义、备份/恢复细节、逐条 FAQ，见 [使用说明.md](使用说明.md)。

---

## 一、下载与安装

1. 到本仓库的 [Releases](../../releases) 页面，下载最新的 `SmartPrint-<版本>-win64.zip`；
2. 解压到任意目录，例如 `D:\Apps\`，得到一个 `SmartPrint` 文件夹；
3. 双击 `SmartPrint\SmartPrint.exe` 启动。**不需要安装 Python，也不需要命令行。**

解压后的结构：

```
SmartPrint\
    SmartPrint.exe          主程序
    _internal\              运行时依赖（PySide6、Python 等）
    config\                 设置（首次启动自动生成 config.json）
    Data\                   任务数据库、待接收目录、单页文件
    logs\                   运行日志
    drivers\                可选：放 SumatraPDF 等外部工具
```

> ⚠️ **`SmartPrint.exe` 不能单独拷走**，它必须和 `_internal` 文件夹待在一起。要换电脑，整个 `SmartPrint` 文件夹一起复制。
>
> ⚠️ 不要解压到 `C:\Program Files` 下——那里默认不允许普通程序写文件，程序建不了 `Data\` 和 `logs\`。

## 二、使用前要准备的三样东西

| 需要 | 说明 |
| --- | --- |
| **一台真实打印机** | 真正出纸的那台。PDF24、Microsoft Print to PDF 这类虚拟打印机会被识别出来并拒绝使用。 |
| **SumatraPDF** | 程序靠它把单页 PDF 静默发到打印机。没有的话去 [sumatrapdfreader.org](https://www.sumatrapdfreader.org/download-free-pdf-viewer) 下载，程序会自动在常见安装目录、`drivers\`、`PATH`、注册表里找。 |
| **PDF24**（或同类虚拟打印机） | 只用来**接收**打印任务：任何软件里 `Ctrl+P` 选 PDF24，它会把 PDF 写进 `Data\incoming`，SmartPrint 监视这个目录并自动登记任务。[下载 PDF24](https://www.pdf24.org/en/) ⚠️ **首次使用必须先设好它的输出目录**，见下一节。 |

### 让 PDF24 把 PDF 存进 SmartPrint 的目录（必须做一次）

PDF24 装好之后默认**不是**「自动存到某个文件夹」，可能每打一份都弹助手窗口让你手动另存。得改一次设置，让它安静地写进 `Data\incoming`：

1. **先启动一次 SmartPrint**——它会把 `Data\incoming` 目录建出来（PDF24 不会替你建目录）。
2. 打开 PDF24 的设置：开始菜单 → **PDF24 Creator** →「设置」；或直接运行安装目录里的 `pdf24-Settings.exe`（如 `C:\Program Files\PDF24\pdf24-Settings.exe`）。
3. 左侧选「**PDF打印机**」。
4. 在「**PDF打印机工具**」里选「**打印后自动保存文档**」（默认那项是「在 PDF24 助手中打开」，那样每份都要你手点保存，程序等不到文件）。
5. 在「**自动保存**」里把「**输出目录**」设成 `<SmartPrint 文件夹>\Data\incoming`，例如 `D:\Apps\SmartPrint\Data\incoming`。
6. 「**文件名称**」保持默认模板 `%Y-%m-%d_%H-%M-%S_$id_$fileName`。**不要把 `$id` 删掉**——程序靠这一段识别「同一份文档被重复打印」，去掉就只能按整个文件名去重了。
7. **取消勾选**「保存前询问文件名」——勾着的话每打一份都弹框，任务不会自动进队列。
8. 「保存后打开目标文件夹」建议不勾，否则每打一份都弹出一个资源管理器窗口。

**怎么验证设对了**：随便打一份 PDF 到 PDF24，目标目录里应出现类似 `2026-11-05_16-17-26_1FD3F68B_文档1.pdf` 的文件，主窗口列表里立刻多出一条「待处理」。没出现就先看 PDF24 的输出目录填的是不是这个路径，再按 `F5` 手动扫一次。

> ⚠️ 这个输出目录是**绝对路径**记在 PDF24 里的。以后把 `SmartPrint` 文件夹挪了位置、或者换电脑重装，都要回来把这一项改成新路径——否则 PDF24 还在往旧目录写，程序永远等不到文件。

## 三、第一次设置

菜单「帮助 → 设置」，或按 `Ctrl+,`。

| 项目 | 怎么设 |
| --- | --- |
| **打印用打印机** | 从下拉列表选**真实**那台。注意 Windows 里的完整名字可能带后缀，例如 `HP LaserJet 1020 1016811`，选下拉里实际那一项。 |
| **SumatraPDF 路径** | 留空表示自动查找；找不到时手动选 `SumatraPDF.exe`。 |
| **每批纸张数** | 默认 **5 张纸**（= 最多 10 页内容）。手动翻面嫌麻烦就调小。 |
| **翻面方向** | ⚠️ **必须实测后再定**，见下。 |

### 关于翻面方向（最容易出错的一步）

不同打印机不一样，只能试出来：

- **沿长边翻面（左右翻，像翻书）**——默认值；
- **沿短边翻面（上下翻，像翻台历）**。

**建议先做个小实验**：拿一个 2 页的 PDF 打一遍。正面第 1 页 → 翻面 → 背面第 2 页。检查第 2 页是否印在第 1 页的**背面**、方向是否正确。不对就换另一个方向。方向对了再上正式文档。

## 四、日常使用流程

### 1. 把 PDF 交给它

任意软件里 `Ctrl+P` → 打印机选 **PDF24** → 打印。任务会自动出现在主窗口列表里，状态「待处理」。
（没自动出现就按 `F5` 手动扫描一次。）

### 2. 手动双面打印（主流程）

选中任务 → `Ctrl+D`，然后照着做：

1. 点「**开始手动双面打印**」；
2. 点「**提交当前页**」——程序只发**一页**；
3. 到打印机取纸，检查是否完整、清晰、没卡纸；
4. 没问题点「**打印正常：确认完整出纸**」，程序才推进到下一页；
5. 一批的正面（1、3、5、7、9 页）全部确认后，窗口提示**等待翻面**；
6. 按示意图把整批纸翻面、整理好、放回进纸托盘，点「**确认已翻面，开始打印背面**」；
7. 背面**从纸堆最上面那张打起**，即按纸张编号**降序**：5 张纸依次是 **10、8、6、4、2 页**（不是 2、4、6、8、10）。同样一页一页提交、一页一页确认；
8. 所有纸两面都确认完，任务变「已完成」。

> **核心规则：命令发出去 ≠ 纸打出来了。** 就算系统打印队列显示「已打印」也不算——只有你点了「确认完整出纸」，这一面才算完成。

### 3. 出问题了

**卡纸 / 缺纸 / 印糊了**：点「**打印异常**」，填一句原因。程序会：

- 把这**一整张纸**正反两面都作废（不管异常发生在哪一面）；
- 把它放进待补打清单，**当前这一轮继续打其它正常的纸**；
- 本轮结束后自动开始「第 1 轮补打」，仍是一页一页确认；补打再出问题就进「第 2 轮」；
- 直到最后一张纸两面都确认过，任务才算完成。

**要暂停**：点「暂停任务」。已提交未确认的那一页保留为「待核对」，恢复后不会自动重发，仍需你看一眼。

**要重来**：点「取消任务」，记录全部保留，之后重新开一次手动双面打印即可。

### 4. 完成之后

- 「文件 → 归档已完成任务」把源 PDF、单页文件、`summary.json` 复制到 `Data\completed\archive\`；
- 「删除任务」会把源 PDF 归档到 `Data\completed\removed\`，不会直接删；
- 「文件 → 备份数据 / 从备份恢复」打包或还原数据库与配置（**恢复后需重启程序**）。

## 六、常见问题

**Q：提示「找不到可用打印机」或「看起来是虚拟打印机」。**
到设置里从下拉列表选一台**真实**打印机，别选 PDF24 / Microsoft Print to PDF。

**Q：打印机明明在，为什么名字要选带后缀的那个？**
Windows 里完整名称可能是 `HP LaserJet 1020 1016811`，SumatraPDF 需要完整名字才能发命令。从下拉列表选实际那一项即可。

**Q：点了「提交当前页」，打印机没动静。**
看窗口里的提示和「本次结果」。常见原因：打印机脱机、缺纸、上一页还堵在队列里、SumatraPDF 路径不对。程序**不会自动重试**——处理完再点一次提交。

**Q：`Ctrl+P` 打到 PDF24 了，列表里却没有任务。**
九成是 PDF24 的输出目录没设成 `Data\incoming`，见前面「让 PDF24 把 PDF 存进 SmartPrint 的目录」。另外检查「保存前询问文件名」有没有关掉、程序窗口是不是开着这个 `Data` 目录对应的同一份程序。按 `F5` 可手动扫描一次。

**Q：翻面后背面印倒 / 印反了。**
换一个「翻面方向」，下次生效。已经打坏的纸按「打印异常」整张补打。

**Q：为什么背面是先打第 10 页、再打第 8 页？**
正面按纸张编号从小到大打，最后打的那张纸落在出纸托盘最上面；整批翻面放回后，最上面那张最先进纸。所以背面必须从后往前打：10、8、6、4、2。

**Q：程序崩溃 / 断电了，进度还在吗？**
在。每一面的状态、每次翻面确认、每条打印命令都写在 SQLite 里。重开后已确认的纸不会重打，提交过但没确认的那页会停在「等待用户确认」。

**Q：能一次把整个 PDF 发完吗？**
不能，这是刻意限制。任何时刻最多只有**一页**已提交未确认，这样出错时你只需要检查一张纸。

**Q：能做自动双面 / 网络打印服务器 / 手机端 / OCR 吗？**
不做，第一版范围之外。它只解决「手动双面的过程管理」。

## 七、数据都在哪

```
Data\incoming\                 PDF24 的输出目录（任务接收，必须和 PDF24 设置里的一致）
Data\jobs\<任务号>\            original.pdf、page_001.pdf…、plan.json
Data\database\smartprint.db    任务数据库（SQLite）
Data\completed\removed\        删除任务时归档的源 PDF
Data\completed\archive\        归档的任务目录
Data\backups\                  备份 zip
logs\smartprint.log            运行日志（5MB 轮转，保留 5 份）
config\config.json             设置
```

命令行自查（排错时有用）：

```
SmartPrint.exe --version
SmartPrint.exe --self-test 报告.txt
```

## 八、从源码运行 / 自己打包

```bash
pip install -r requirements.txt      # Python 3.13 + PySide6 + PyMuPDF + watchdog
python -m app.main                   # 源码运行
```

打包成可分发目录（PyInstaller onedir）：

```bash
python -m PyInstaller --noconfirm --clean SmartPrint.spec
# 产物在 dist\SmartPrint\，把 SmartPrint.exe 和 _internal 一起打包即可
```

`tools\` 下是按阶段划分的自动化验收脚本（用假打印机和假 SumatraPDF，不会真的出纸），改代码后建议全跑一遍。

## 九、明确不做的事

- 不判断纸有没有真的打出来——只按你的确认推进；
- 不自动重试、不自动重发、不把系统打印队列状态当成打印成功；
- 不做自动双面（用的是打印机的单面进纸能力）；
- 不做多打印机调度、优先级队列、云同步、手机端。

这些不是没做完，是第一版故意不做——先让「逐面确认 + 整张补打」这条主线在真实打印机上稳定下来。
